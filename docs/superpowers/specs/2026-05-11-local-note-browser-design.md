# 本地笔记浏览器设计

> 文件说明：本文档记录 Flutter 客户端本地笔记浏览器阶段的目标、范围和技术设计。

## 目标

本阶段把 Flutter 客户端从空壳推进到可上手验证的本地笔记浏览器。用户可以在 Windows 客户端中查看文件夹、笔记列表和笔记详情，并通过内置种子数据验证基础交互。

## 范围

包含：

- 本地数据模型：文件夹、笔记。
- 本地仓储接口：定义笔记读取能力。
- 内存仓储实现：提供稳定种子数据。
- Windows 宽屏三栏布局：文件夹区、笔记列表、详情区。
- 窄屏兼容布局：保留同一数据与选择逻辑，后续给 Android 优化。
- Widget 测试：验证种子笔记展示与选择交互。

不包含：

- 新建、编辑、删除和保存笔记。
- SQLite 落盘。
- Markdown 渲染。
- 图片附件。
- 外部链接跳转。
- 内部笔记链接跳转。
- 登录、同步和后端接口调用。

## 架构

客户端新增三个小模块：

- `features/notes/domain`：保存 `Folder`、`Note` 等纯数据模型。
- `features/notes/data`：保存 `NoteRepository` 接口和内存实现。
- `features/notes/presentation`：保存本地笔记浏览页面组件。

`ShellPage` 不直接写死静态说明，而是挂载 `NoteBrowserPage`。页面内部持有当前选中的文件夹和笔记 ID，通过仓储读取种子数据并渲染 UI。

## 数据模型

`Folder` 字段：

- `id`：稳定文件夹 ID。
- `name`：文件夹名称。

`Note` 字段：

- `id`：稳定笔记 ID。
- `folderId`：所属文件夹 ID。
- `title`：标题。
- `content`：Markdown 原文。
- `updatedAt`：更新时间。

## 交互

启动客户端后默认选中第一个文件夹和该文件夹下第一条笔记。

点击文件夹时：

- 笔记列表切换到该文件夹。
- 自动选中该文件夹下第一条笔记。
- 如果该文件夹没有笔记，详情区显示空状态。

点击笔记时：

- 详情区展示标题、更新时间和正文原文。

## 错误和空状态

本阶段内存仓储不涉及 IO 错误。UI 需要覆盖两种空状态：

- 没有文件夹：提示“暂无文件夹”。
- 当前文件夹没有笔记：提示“暂无笔记”。

## 测试

Flutter 测试覆盖：

- 页面启动后显示默认文件夹、默认笔记标题和正文。
- 点击另一个文件夹后，笔记列表和详情随之切换。
- 点击另一条笔记后，详情区更新。

## 验证方式

```powershell
Set-Location apps/client
flutter analyze
flutter test
flutter run -d windows
```

本阶段完成后，用户可以运行 Windows 客户端并验证基础浏览体验。
