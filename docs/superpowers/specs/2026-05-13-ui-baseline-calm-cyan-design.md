# Calm Cyan UI 基线设计

> 文件说明：本文档记录轻量同步笔记第一版 UI 基线的视觉方向、布局规则和实现边界。

## 目标

把当前默认 Flutter 风格的笔记界面升级为可长期演进的产品界面。第一版 UI 基线优先服务 Windows 桌面端，同时保持 Android 单列布局的视觉一致性。

## 设计方向

采用 `Calm Cyan Workspace`：

- 主色：冷静青色 `#0891B2`。
- 强调色：保存成功、同步状态使用绿色 `#059669`。
- 背景：浅青灰 `#EEF8FB` 与白色内容区组合。
- 字体气质：Inter / Segoe UI / 系统中文字体，偏工具型、现代、清晰。
- 风格：Swiss Modernism 2.0，强调清晰网格、克制装饰、明确层级。

## Windows 布局

Windows 端保留三栏结构，但重做视觉层级：

1. 顶部工具栏：品牌、搜索占位、同步状态、新建入口。
2. 左侧文件夹栏：固定宽度，使用选中态块而不是默认列表样式。
3. 中间笔记列表：轻量卡片，突出标题、摘要、更新时间和保存状态。
4. 右侧详情/编辑区：文档式阅读和写作区域，标题大、正文舒展、按钮分级明确。

## Android 布局

窄屏继续使用单列布局：

- 顶部保留品牌和新建入口。
- 文件夹使用横向筛选芯片。
- 笔记列表在详情之前展示。
- 详情和编辑区使用同一套标题、正文和按钮层级。

## 组件规则

- 主按钮只用于新建、保存等核心动作。
- 编辑、取消、排序等次级动作使用弱按钮。
- 加载、错误、空状态统一使用居中状态面板。
- 不使用 emoji 作为图标。
- 不使用大面积渐变、装饰圆点或厚重卡片墙。
- 卡片圆角不超过 12px，页面主要容器圆角不超过 18px。

## 本阶段范围

- 修改主题色、按钮、输入框、卡片、列表和页面背景。
- 重做 `NoteBrowserPage` 的三栏和窄屏布局。
- 保留现有 SQLite 仓储和编辑逻辑。
- 保留现有功能测试语义。

## 暂不包含

- 深色模式。
- 动画和微交互细节。
- 搜索真实功能。
- 标签、图片附件、内部链接预览。
- Android 真机专项截图验收。

## 验证方式

- `flutter analyze` 无问题。
- `flutter test` 全部通过。
- Windows 端可以运行 `flutter run -d windows` 人工查看整体视觉。
- 现有新建、编辑、保存、取消和 SQLite 持久化行为不回退。
